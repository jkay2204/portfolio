# Vũ Gia Khiêm — Portfolio

A minimal, modern portfolio built with vanilla HTML, CSS, and JavaScript.

## Deploy with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**.
4. Save and open the generated Pages URL.

## Customize

Update the email address, social links, project descriptions, and project links in `index.html`.
